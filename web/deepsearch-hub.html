البحث العكسي العميق

ارفع صورة أو فيديو، أو ضع رابطاً مباشراً، ثم ابحث في ستة محركات مختلفة. كل محرك يملك فهرساً مختلفاً، لذلك تظهر نتائج لا يجدها Google.

رابط مباشر لصورة (ينتهي غالباً بـ jpg أو png أو webp) أو لملف فيديو mp4. البحث بالرابط هو الأدق لأن المحرك يجلب الصورة الأصلية بنفسه.

  • قصّ الجزء المهم (وجه، شعار، مبنى). المحركات تطابق الأجزاء الصغيرة أفضل من صورة مزدحمة.

DNS آمن وتجاوز الحجب

مزوّد الإنترنت يحجب كثيراً من المواقع ويفرض "البحث الآمن" عبر خوادم DNS الخاصة به. عند استخدام DNS مشفّر مثل Cloudflare على جهازك، تُحل أسماء المواقع مباشرة ولا يستطيع المزوّد رؤيتها أو تبديلها. هذا لا يتجاوز الحجب القائم على عنوان IP؛ لذلك ستجد في الأسفل أدوات أقوى.

هل الموقع محجوب عبر DNS؟

يحل الاسم عبر Cloudflare وGoogle بشكل مشفّر (DoH). إذا ظهرت عناوين هنا والموقع لا يفتح عندك، فالحجب غالباً من DNS مزوّدك وسيحله تفعيل DNS آمن.

المزوّدون

التفعيل خطوة بخطوة

لا يستطيع أي موقع تغيير إعدادات جهازك بنفسه؛ هذه الخطوات تأخذ دقيقة. القيم أدناه لـ Cloudflare، ويمكنك نسخ قيم أي مزوّد آخر من البطاقات بالأعلى.

Android 9 وأحدث (مشفّر لكل التطبيقات)
  1. الإعدادات ← الشبكة والإنترنت ← DNS الخاص (في Samsung: الاتصالات ← إعدادات اتصال إضافية ← DNS خاص).
  2. اختر اسم مضيف مزوّد DNS الخاص.
  3. اكتب one.one.one.one ثم احفظ.
iPhone و iPad
  1. الأسهل: ثبّت تطبيق 1.1.1.1 من App Store واضغط زر التفعيل. يشفّر DNS (أو كل الاتصال مع WARP).
  2. بدون تطبيق: الإعدادات ← Wi-Fi ← (i) بجانب الشبكة ← تكوين DNS ← يدوي.
  3. احذف الخوادم الموجودة وأضف 1.1.1.1 و 1.0.0.1. هذه الطريقة غير مشفّرة وتنطبق على شبكة Wi-Fi هذه فقط.
Windows 11
  1. الإعدادات ← الشبكة والإنترنت ← Wi-Fi أو Ethernet ← خصائص الأجهزة.
  2. بجانب "تعيين خادم DNS" اضغط تحرير ← يدوي ← فعّل IPv4.
  3. المفضّل 1.1.1.1 والبديل 1.0.0.1، ثم اجعل "DNS عبر HTTPS" على تشغيل (قالب تلقائي).
  4. كرر نفس الشيء لـ IPv6 بالقيمتين 2606:4700:4700::1111 و 2606:4700:4700::1001.
macOS
  1. إعدادات النظام ← الشبكة ← اختر الاتصال ← التفاصيل ← DNS.
  2. اضغط + وأضف 1.1.1.1 و 1.0.0.1.
  3. للتشفير الكامل ثبّت تطبيق 1.1.1.1 / WARP.
Chrome و Edge و Brave (المتصفح فقط)
  1. افتح chrome://settings/security (في Edge: edge://settings/privacy).
  2. فعّل استخدام DNS آمن واختر Cloudflare (1.1.1.1) من القائمة.

إذا كان الخيار رمادياً فالمتصفح تديره جهة (عمل أو مدرسة) ولا يمكن تغييره من هنا.

Firefox (المتصفح فقط)
  1. الإعدادات ← الخصوصية والأمان ← انزل إلى DNS عبر HTTPS.
  2. اختر حماية قصوى ثم المزوّد Cloudflare.
الراوتر (كل أجهزة البيت)
  1. افتح صفحة الراوتر (غالباً 192.168.1.1) وسجّل الدخول.
  2. ابحث عن إعدادات DHCP أو DNS وضع 1.1.1.1 و 1.0.0.1.

هذه الطريقة غير مشفّرة، وبعض مزوّدي الإنترنت يعيدون توجيه منفذ 53 رغماً عنها. الطرق المشفّرة أعلاه أضمن.

عندما لا يكفي DNS

إذا بقي الموقع محجوباً بعد تفعيل DNS آمن، فالحجب على مستوى عنوان IP أو اسم الموقع في الاتصال. هذه أدوات موثوقة تمرر الاتصال كله عبر نفق مشفّر:

Cloudflare WARPمجاني وسريع، يشفّر كل الاتصال. أفضل نقطة بداية. Psiphonمصمم خصيصاً لتجاوز الرقابة، يتبدّل بين طرق الاتصال تلقائياً. Tor Browserأقوى تجاوز وخصوصية، لكنه أبطأ. Orbotشبكة Tor لتطبيقات Android وiPhone. Proton VPN المجانيبلا حد للبيانات ولا سجلات، من شركة Proton السويسرية.

المتصفح

افتح أي صفحة مباشرة أو عبر وسيط: خادم الترجمة من Google يجلب الصفحة نيابةً عنك، والأرشيف يعرض آخر نسخة محفوظة. كلاهما يعمل غالباً حتى لو كان الموقع الأصلي محجوباً.
