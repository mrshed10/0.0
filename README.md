# سفر (Safar) — متصفح أندرويد خفيف يركّز على الخصوصية والترجمة الحية

متصفح حديث بتجربة قريبة من Chrome وBare: شريط عنوان علوي أو سفلي، وشريط أدوات قابل للتخصيص، وإيماءات، ودعم إضافات Firefox، وترجمة حية مدمجة للنصوص والمانغا والفيديو.

---

## 1) المعمارية التقنية المقترحة

| الطبقة | الاختيار | السبب |
|---|---|---|
| اللغة | **Kotlin** + Coroutines/Flow | اللغة الرسمية لأندرويد، وتسهّل التزامن مع الشبكة وOCR |
| الواجهة | **Jetpack Compose + Material 3** (ألوان ديناميكية، اتجاه RTL) | تخصيص الواجهة سهل، والأداء جيد، والكود أقل |
| محرك العرض | **GeckoView** (محرك Firefox) | **هو المحرك الوحيد القابل للتضمين في أندرويد الذي يدعم إضافات WebExtensions**. أما Android WebView (Chromium) فلا يدعم الإضافات إطلاقاً. ويوفر كذلك HTTPS-Only، وحماية التتبع، وعزل الكوكيز، ومقاومة البصمة بشكل أصلي |
| الإضافات | `WebExtensionController` في GeckoView | تثبيت ملفات ‎.xpi من AMO، وتمكين وتعطيل، وأزرار `browserAction` ونوافذها المنبثقة |
| الترجمة على الجهاز | **ML Kit Translation** + **Language ID** | مجانية وخاصة وتعمل دون إنترنت، وهي الافتراضي والملاذ الأخير |
| الترجمة السحابية | **Google Cloud Translation v2**، و**DeepL API**، و**Claude** (Anthropic Java SDK)، و**Gemini** (REST) | لكل مزود نقطة قوة، ويختار بينها موجّه ذكي |
| OCR | **ML Kit Text Recognition v2** (لاتيني/ياباني/صيني/كوري/ديفاناغاري) + **Tesseract4Android** (عربي/فارسي/روسي/عبري...) | ML Kit سريع، وTesseract يغطي اللغات التي لا يدعمها ML Kit |
| التخزين | DataStore (الإعدادات بصيغة JSON)، وملفات JSON (الإشارات والجلسات)، وAndroid Keystore (مفاتيح API) | خفيف ولا يحتاج قاعدة بيانات |
| النسخ الاحتياطي | PBKDF2-SHA256 (210 ألف تكرار) ← AES-256-GCM | ملف محمول ومشفّر بكلمة مرور، ويكشف أي عبث بالمحتوى |

### مخطط المكونات

```
MainActivity (Compose)
 ├─ OnboardingScreen / BrowserScreen / Settings / Extensions / Bookmarks
 └─ BrowserViewModel ───────────────────────────────────────────────┐
     ├─ TabManager ── GeckoSession × N (Navigation/Progress/Content/Media delegates)
     ├─ PrivacyController ── GeckoRuntimeSettings + إضافة privacyshield (WebRTC/Canvas)
     ├─ ExtensionManager ── WebExtensionController (تثبيت/تمكين/أزرار/Popup)
     ├─ LiveTranslateController ◄── Native Messaging ──► إضافة livetranslate (content.js)
     │    ├─ ProviderRouter ── OnDevice | Google | DeepL | Claude | Gemini  (+ LRU cache)
     │    └─ OcrRouter ── ImagePreprocessor → MlKitOcr | TesseractOcr → OcrPostProcessor
     ├─ DownloadHandler (DownloadManager أو مدير تحميل خارجي)
     └─ MediaPlaybackService (خدمة أمامية + إشعار وسائط)
```

### كيف تعمل الترجمة الحية

* **نصوص (افتراضي):** يرصد `content.js` عُقد النص التي تقترب من الشاشة فقط عبر `IntersectionObserver`، ويرسلها على دفعات (40 مقطعاً أو 4500 حرف كحد أقصى) إلى التطبيق، ثم يستبدلها في مكانها. يتابع `MutationObserver` المحتوى الجديد عند التمرير اللانهائي وفي تطبيقات الصفحة الواحدة (SPA). هذا الوضع الأسرع والأخف لأنه لا يحتاج OCR.
* **مزودو الترجمة بدون مفتاح:** «ترجمة Google المجانية» (نقطة ويب عامة، جودة جيدة، قد تُقيَّد عند كثرة الطلبات) و«ML Kit على الجهاز» (بلا إنترنت، خاص تماماً). الوضع التلقائي يستخدمهما دائماً كملاذ أخير، فتعمل الترجمة حتى بلا أي مفتاح. Google Cloud وDeepL وClaude وGemini تتطلب مفتاحاً، وتطلبه الواجهة عند اختيارها.
* **صور / مانغا:** عند توقف التمرير يخفي السكربت ترجماته السابقة، ثم يطلب لقطة عبر `GeckoView.capturePixels()`. تمر اللقطة بمرحلة تحسين (تكبير الصورة، ثم تحويلها إلى الرمادي، ثم مط التباين)، ثم OCR، ثم تنظيف النتيجة (دمج أسطر الفقاعة الواحدة، وتصحيح أخطاء شائعة مثل `|` و`0`، وحذف الضجيج)، ثم الترجمة. بعدها يحلل `BubbleAnalyzer` كل فقاعة: يأخذ لون الخلفية، ويحدد إن كانت موحّدة، ويملأ داخلها حتى الحد الأسود. في نمط «تنظيف الفقاعة» يُطلى النص الأصلي بلون الفقاعة نفسه داخل حدودها فقط، وتُكتب الترجمة داخلها بحجم خط يُضبط تلقائياً واتجاه من اليمين لليسار للعربية. أما على الرسم أو الخلفيات المنقطة فيتحول تلقائياً إلى نص فقط بتوهج خفيف حتى لا يشوّه الرسم. الأنماط الأخرى: «شبه شفاف» (عتامة 0–35%) و«نص فقط». لمس الترجمة يعرض النص الأصلي، وزر العين يُخفي الترجمات أو يُظهرها. تُكتشف لغة المصدر تلقائياً بتشغيل معرّفي النص الياباني والكوري معاً، وكلاهما يقرأ الإنجليزية أيضاً.
* **فيديو:** إذا كان للفيديو مسار ترجمة نصي (VTT) تُترجم أسطره عند `cuechange`، وهذه الطريقة أدق ولا تحتاج OCR. وإلا يُجرى OCR دوري للثلث السفلي من الفيديو، مع تجاهل الإطارات التي لم يتغير نصها، وتمرير آخر الأسطر كسياق لنموذج الذكاء الاصطناعي.
* **المربع الزجاجي العائم:** يُسحب ويُغيَّر حجمه، ويترجم مرة واحدة أو بشكل متكرر. في وضع النصوص يقرأ نص الـ DOM داخل حدوده أولاً، ويلجأ إلى OCR إذا لم يجد نصاً.

### الاختيار الذكي لمصدر الترجمة (`ProviderRouter`)

| المحتوى | الترتيب التلقائي |
|---|---|
| حوارات أو عامية (أكثر من 40% من المقاطع فيها علامات اقتباس أو شرطات حوار أو تعجب متكرر) | Claude ← Gemini ← DeepL ← Google ← على الجهاز |
| نصوص قصيرة (قوائم وأزرار، بمتوسط أقل من 40 حرفاً) | Google ← على الجهاز ← DeepL ← نماذج الذكاء الاصطناعي |
| فقرات طويلة | DeepL (إذا كان يدعم اللغة) ← Google ← نماذج الذكاء الاصطناعي ← على الجهاز |
| مانغا أو فيديو | Claude ← Gemini ← DeepL ← Google ← على الجهاز |

يُتخطى تلقائياً كل مزود ليس له مفتاح أو لا يدعم اللغة. وعند فشل الطلب أو رفض النموذج ينتقل الموجّه إلى المزود التالي. ولا تكرر الذاكرة المؤقتة (LRU) طلب أي نص تُرجم من قبل.

**ملاحظة عن Claude:** النموذج الافتراضي `claude-opus-5-5` مع `effort=LOW` لتقليل زمن الاستجابة، ويمكن تغييره من الإعدادات، فمثلاً `claude-haiku-5-5` أسرع وأرخص بكثير ويناسب الترجمة الكثيفة. التعليمات المرسلة للنموذج موجودة في `translate/LlmPrompt.kt`، وتطلب منه الحفاظ على النبرة والعامية والأسماء والمؤثرات الصوتية في المانغا، وأن يعيد مصفوفة JSON بالطول نفسه للمدخلات.

## 2) المراحل (Milestones)

التفاصيل الكاملة ومعايير القبول في [`docs/MILESTONES.md`](docs/MILESTONES.md).

| المرحلة | المحتوى | الحالة في هذا الكود |
|---|---|---|
| **M1 — MVP** | GeckoView، والتبويبات (عادية ومتخفية)، وشريط العنوان والبحث، والإعداد الأولي (محرك البحث، وحظر الإعلانات، ومكان الشريط)، والإعدادات، وحفظ الجلسة واستعادتها، والنوافذ المنبثقة الأساسية | ✅ مكتوب |
| **M2 — الخصوصية** | HTTPS-Only، وحماية التتبع الصارمة، والكوكيز الخارجية، وFPP، وإضافة privacyshield (إخفاء IP المحلي في WebRTC + تشويش Canvas)، واستثناء المواقع | ✅ مكتوب |
| **M3 — التخصيص** | تخصيص أزرار شريط الأدوات وترتيبها، والتبويبات العمودية، وإيماءات السحب على الشريط، وثيم خاص بالتصفح المتخفي | ✅ مكتوب |
| **M4 — الإضافات** | إدارة الإضافات، وتثبيتها من AMO أو رابط xpi، وتثبيت أزرارها في الشريط، ونوافذها المنبثقة، وقائمة إضافات مقترحة | ✅ مكتوب |
| **M5 — الترجمة الحية: النصوص** | content.js، والموجّه الذكي، وخمسة مزودين، والذاكرة المؤقتة، ولوحة التحكم | ✅ مكتوب |
| **M6 — الترجمة الحية: الصور والفيديو** | OCR (ML Kit/Tesseract) مع التحسين والتنظيف، ومربعات المانغا، وترجمة VTT والترجمة المحروقة، والمربع الزجاجي العائم | ✅ مكتوب |
| **M7 — الوسائط والتحميل والنسخ الاحتياطي** | التشغيل في الخلفية مع إشعار، وDownloadManager أو مدير تحميل خارجي، والنسخ الاحتياطي المشفر، والتعيين كمتصفح افتراضي | ✅ مكتوب |
| **M8 — الصقل** | منتقي الملفات وأذونات الكاميرا والموقع، والبحث داخل الصفحة، ووضع سطح المكتب، والاقتراحات، والسجل، واختبارات واجهة | ⏳ مخطط |

## 3) التشغيل

### المتطلبات
* Android Studio (Ladybug أو أحدث) مع JDK 17 وAndroid SDK 35.
* جهاز أو محاكي **arm64-v8a** أو **x86_64** بنظام Android 8.0 (API 26) أو أحدث. يُفضّل جهاز حقيقي، لأن GeckoView ثقيل على المحاكي.

### الخطوات
```bash
git clone <repo> && cd SafarBrowser
```
افتح المجلد في Android Studio، وانتظر حتى ينتهي Gradle Sync، ثم اختر Run. أو من الطرفية:
```bash
./gradlew :app:assembleDebug
```
```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```
```bash
adb shell am start -n app.safar.browser/.MainActivity
```

> **إصدار GeckoView:** القيمة `geckoview = "140.+"` في `gradle/libs.versions.toml` تجلب أحدث إصدار من فرع 140. واجهة GeckoView تتغير بين الإصدارات الرئيسية، والمواضع الحساسة لذلك في الكود عليها التعليق `// GV-API`، وأهمها `onInstallPromptRequest` و`fingerprintingProtection` و`onOpenPopup`. إذا فشل البناء عند أحدها، فطابق توقيع الدالة مع Javadoc الإصدار الذي تستخدمه، ثم ثبّت رقم الإصدار بدقة.

### مفاتيح الترجمة (اختيارية)
تعمل الترجمة على الجهاز (ML Kit) دون أي مفتاح. لتفعيل باقي المزودين افتح **الإعدادات ← الترجمة الحية** وأدخل المفاتيح، وهي تُخزَّن مشفّرة في Android Keystore ولا تدخل في النسخة الاحتياطية.
* Google Cloud Translation: من Google Cloud Console، بعد تفعيل Cloud Translation API.
* DeepL: من حساب DeepL API (المفتاح المجاني ينتهي بـ `:fx`).
* Claude: من console.anthropic.com.
* Gemini: من Google AI Studio.

> للنشر العام يُفضّل وضع خادم وسيط (proxy) يحمل المفاتيح بدلاً من أن يُدخلها كل مستخدم بنفسه.

## 4) الاختبار

### اختبارات الوحدة (JVM)
```bash
./gradlew :app:testDebugUnitTest
```
تغطي هذه الاختبارات المنطق الصافي في 36 حالة، موزعة على `UrlUtilsTest` و`BackupCryptoTest` و`ProviderRouterTest` و`LlmPromptTest` و`OcrPostProcessorTest`.

### تصحيح GeckoView والإضافات
* نسخة Debug تفعّل `remoteDebuggingEnabled`: وصّل الجهاز ثم افتح `about:debugging` في Firefox على الحاسوب لفحص الصفحات وسكربتات الإضافات (content.js).
* سجلات Gecko:
```bash
adb logcat -s GeckoConsole:* GeckoView:* PrivacyShield:*
```

### قائمة اختبار يدوي
| الميزة | الخطوات | النتيجة المتوقعة |
|---|---|---|
| الإعداد الأولي | تثبيت جديد | ثلاث خطوات، وتظهر الخيارات نفسها لاحقاً في الإعدادات |
| HTTPS-Only | افتح `http://http.badssl.com` | صفحة تحذير من Gecko فيها خيار المتابعة |
| حظر التتبع | افتح https://coveryourtracks.eff.org | حظر المتتبعات، وبصمة Canvas تتغير بين الجلسات |
| إخفاء IP المحلي | افتح https://browserleaks.com/webrtc | لا يظهر عنوان 192.168.x.x |
| استثناء موقع | من القائمة اختر "استثناء هذا الموقع" | تُعاد تحميل الصفحة دون حماية، ويظهر الموقع في الإعدادات |
| الإضافات | الإضافات ← uBlock Origin ← تثبيت ← تثبيت الزر في الشريط | يظهر زرها في الشريط، ولمسه يفتح نافذتها المنبثقة |
| الإيماءات | اسحب أفقياً على الشريط أو للأعلى | ينتقل بين التبويبات أو يفتح مبدّل التبويبات |
| ترجمة النصوص | فعّل الترجمة (نصوص ← العربية) في موقع إنجليزي | تُترجم الفقرات المرئية أولاً، ويستمر ذلك مع التمرير والتنقل |
| المانغا | نوع المحتوى "صور / مانغا" في موقع مانغا | تظهر مربعات فوق الفقاعات بعد توقف التمرير، ولمسها يعرض الأصل |
| الفيديو | فيديو بترجمة VTT، أو بترجمة محروقة | ترجمة فوق الفيديو |
| المربع العائم | طريقة العرض "مربع زجاجي عائم" | سحب وتحجيم، ثم "ترجم" أو "مباشر" |
| الصوت في الخلفية | شغّل فيديو أو صوتاً ثم اقفل الشاشة | يستمر التشغيل مع إشعار فيه زر إيقاف وتشغيل |
| التنزيل | نزّل ملفاً مع تفعيل مدير تحميل خارجي ثم دون تفعيله | يُسلَّم الرابط للتطبيق الخارجي، أو يتولاه DownloadManager |
| النسخ الاحتياطي | احفظ نسخة، ثم امسح بيانات التطبيق، ثم استعدها | تعود الإعدادات والإشارات والتبويبات والإضافات، وتُرفض كلمة المرور الخاطئة |
| المتصفح الافتراضي | الإعدادات ← تعيين كمتصفح افتراضي، ثم افتح رابطاً من تطبيق آخر | يُفتح الرابط في سفر |
