# مواعيد الرواتب — Saudi Salaries & Countdown App (Android)

تطبيق أندرويد (Kotlin + Jetpack Compose) لعرض مواعيد صرف الرواتب والدعم والمناسبات في المملكة،
مبني وفق وثيقة المتطلبات مع التعديلات الثلاثة الجوهرية:

1. **عداد تنازلي مخصص** — إضافة عداد لأي موعد شخصي بتاريخ هجري (أم القرى) أو ميلادي مع الوقت واللون،
   ويعرض الأيام والساعات والدقائق والثواني بشكل مباشر.
2. **ودجت شامل قابل للتخصيص** — ودجت (Jetpack Glance) يعرض أي بطاقة من التطبيق، مع التحكم في
   لون الخلفية ولون النص ولون الأيقونات، وعدد البطاقات، ومعاينة مباشرة. يتكيف مع حجم الودجت.
3. **بدون إعلانات إطلاقاً** — لا توجد مكتبات إعلانات أو تتبع، والتطبيق لا يطلب صلاحية الإنترنت أصلاً.

## الميزات

| القسم | المحتوى |
|---|---|
| الرئيسية | التاريخ الهجري والميلادي، زر سريع لإضافة عداد، عداداتي، جميع المواعيد القادمة |
| الرواتب | رواتب الموظفين (27)، الضمان الاجتماعي، الدعم السكني، التأهيل الشامل + المواعيد القادمة |
| التقاعد | رواتب التقاعد (1 من كل شهر) |
| حساب المواطن | الدفعة الشهرية (10 من كل شهر) |
| المزيد | المناسبات، حساب العمر (هجري/ميلادي)، محول التاريخ، حاسبة الفواتير (ضريبة 15٪)، تخصيص الودجت، الوضع الداكن |

في كل بطاقة: 🔔 تنبيه مخصص (يوم قبل الموعد الساعة 9 صباحاً) و ⭐ «إظهار كودجت على الشاشة الرئيسية».

قواعد عطلة نهاية الأسبوع (الجمعة/السبت): الرواتب الحكومية الجمعة ← الخميس، السبت ← الأحد؛
بقية الدفعات تُقدَّم إلى الخميس. جميع القواعد في ملف واحد:
`app/src/main/java/com/saudi/salariesapp/data/PaymentSchedule.kt` — عدّلها عند صدور إعلان رسمي مختلف.

## الهيكلة (MVVM)

```
com.saudi.salariesapp/
├── data/            # EventModel، التقويم الهجري، جدول الصرف، التخزين المحلي، ViewModel
├── ui/
│   ├── screens/     # الرئيسية، الرواتب، التقاعد، حساب المواطن، المزيد والحاسبات، محرر الودجت
│   ├── components/  # البطاقات، العداد التنازلي، منتقي الألوان، نافذة إضافة عداد
│   └── theme/       # الألوان والوضع الداكن واتجاه RTL
├── widget/          # SalariesWidget (Glance) + شاشة إعداد الودجت
├── reminders/       # التنبيهات (AlarmManager) وإعادة الجدولة بعد إعادة التشغيل
└── MainActivity.kt  # نقطة البداية والتنقل السفلي
```

- التحويل الهجري يعتمد `java.time.chrono.HijrahDate` (جداول أم القرى الرسمية) — لذلك الحد الأدنى Android 8.0 (API 26).
- التخزين محلي عبر `SharedPreferences` (العدادات، ألوان الودجت، التنبيهات، الوضع الداكن).

## البناء

افتح المشروع في Android Studio، أو:

```bash
./gradlew :app:assembleDebug      # APK
./gradlew :app:testDebugUnitTest  # اختبارات التقويم وجدول الصرف
```

## غير مُنفَّذ بعد

حالة الطقس ومؤشر تاسي يحتاجان مصدر بيانات عبر الإنترنت (ومفتاح API)، وحاسبة سلم الرواتب تحتاج جداول
السلالم الرسمية؛ تُركت عمداً لإبقاء التطبيق بلا إنترنت وبلا تتبع.
