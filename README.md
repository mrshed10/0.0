# أثر — Athar

تطبيق أندرويد أصلي (Kotlin + Jetpack Compose) يجمع الإنتاجية وأسلوب الحياة والروحانيات بتصميم زجاجي
(Glassmorphism)، مع نظام ويدجت قابل للتخصيص بالكامل. موجّه لهواتف سامسونج، ويعمل على Android 8.0 فأحدث.
كل البيانات على الجهاز فقط: لا إعلانات، ولا تتبّع، ولا يحتاج إذن الإنترنت.

## الأقسام

| التبويب | المحتوى |
|---|---|
| الرئيسية | التاريخ الهجري والميلادي، الصلاة القادمة، الراتب القادم، السبحة، العدادات، مهام اليوم، العادات، ملخص الديون، آية اليوم. زر 📌 في البطاقات يضيف ويدجت مباشرة |
| المواعيد | **العدادات** (تنازلي/تصاعدي، هجري أو ميلادي) · **الرواتب** (حسب الدولة، قاعدة الإجازة، يوم صرف هجري أو ميلادي، مواعيد السعودية جاهزة) · **التنبيهات** (مرة/يومي/أسبوعي/شهري/سنوي، هجري أو ميلادي) |
| المهام | **المهام** (إضافة سريعة، أقسام: متأخرة/اليوم/القادمة/بدون موعد/المنجزة) · **العادات** (الأيام المتتالية، أفضل سلسلة، آخر 7 أيام) |
| الديون | أشخاص بلا حد، قيود «أعطيت/أخذت»، الرصيد تلقائي، بحث، اتصال، قفل اختياري بالبصمة |
| الصلاة | **المواقيت** (حساب محلي بالمدينة أو الموقع، 9 طرق، المذهب، القبلة، أذان لكل صلاة بنغمة مخصصة، تنبيه قبل الصلاة) · **السبحة** · **أذكار الصباح والمساء** |
| الإعدادات | الخطوط، الويدجت وبطاقة شاشة القفل، النسخ الاحتياطي المشفّر، قفل الديون |

## الويدجت
- ويدجت واحدة بحجمين، تعرض أي عنصر: الصلاة، عداد، راتب، مهام اليوم (شطب من الشاشة الرئيسية)، عادة أو كل العادات
  (إنجاز بلمسة)، الديون أو رصيد شخص، السبحة (لمسة = تسبيحة)، آية اليوم، التاريخ.
- تخصيص كامل: لون أو تدرّج أو صورة، الشفافية 0–100%، ضبابية الصورة وطبقة فوقها، استدارة الحواف، حافة زجاجية،
  ألوان النص، الخط، وأنماط جاهزة؛ مع معاينة حية.
- **بطاقة شاشة القفل:** سامسونج لا تسمح بويدجت التطبيقات الأخرى على شاشة القفل، فيستخدم أثر إشعاراً صامتاً ثابتاً
  يظهر عليها، مع عدّاد مباشر للصلاة القادمة.
- غير ممكن تقنياً: خلفيات الفيديو داخل الويدجت.

## الخطوط
خطوط مضمّنة (رخصة OFL): تجوّل، أميري، شهرزاد، عارف رقعة، لاله‌زار، ركاس، Poppins. يمكن استيراد أي خط TTF/OTF
(مثل خط ثلث تملكه)، واختيار خط عربي للواجهة وخط إنجليزي منفصل (Android 10+) وخط للآيات والأذكار، وخط لكل ويدجت
(يُرسم كصورة داخل الويدجت).

## الهيكلة

```
com.athar.app
├── MainActivity / AtharApplication
├── navigation/          # الهيكل والتبويبات والشريط الزجاجي
├── core/
│   ├── designsystem/    # الثيم، الزجاج (Haze)، المكوّنات
│   ├── database/        # Room (الإصدار 3 مع ترحيل)
│   ├── data/            # المستودعات، الإعدادات، AppContainer
│   ├── backup/          # النسخ الاحتياطي (JSON + AES-256-GCM اختياري)
│   ├── notify/          # المنبّهات الدقيقة، القنوات، النغمات
│   ├── fonts/           # سجل الخطوط والاستيراد ورسم النص للويدجت
│   ├── calendar/ format/ region/ security/ time/ ui/
├── feature/             # home, counters, tasks, habits, debts, prayer, salary, reminders, dates, settings
└── widget/              # Glance: الويدجت، المحرّر، الخلفيات، بطاقة القفل
```

## البناء

```bash
./gradlew testDebugUnitTest   # اختبارات المنطق (التقويم، الرواتب، الصلاة، التكرار، الديون، النسخ، الويدجت...)
./gradlew assembleDebug       # app/build/outputs/apk/debug/app-debug.apk
```

يبني GitHub Actions ملف APK مع كل push (`.github/workflows/android.yml`) باسم `athar-debug-apk`.

## ملاحظات
- مواعيد الرواتب الافتراضية تقديرية ويمكن تعديلها.
- النصوص القرآنية المضمّنة قليلة ومكتوبة بلا تشكيل؛ لمكتبة أكبر يُنصح بمصدر موثّق مثل Tanzil.
- النسخة الاحتياطية لا تشمل ملفات الخطوط والنغمات والصور المستوردة.
