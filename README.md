# مواعيد الرواتب السعودية (بلا إعلانات)

تطبيق Android أصلي (Kotlin + Jetpack Compose) لعرض مواعيد صرف الرواتب والخدمات في المملكة،
مع ثلاث إضافات جوهرية:

1. **عداد تنازلي مخصص** لأي موعد شخصي (اختبار، زواج، سداد فاتورة...) بتاريخ هجري أو ميلادي ووقت محدد،
   ويعرض الأيام والساعات والدقائق والثواني مباشرة.
2. **ودجت شامل قابل للتخصيص** (Jetpack Glance): اختيار لون الخلفية والنص والأيقونات، الشفافية، حجم الخط،
   واختيار أي بطاقة من التطبيق لتظهر فيه. يتكيّف مع حجم الودجت (صغير/متوسط/كبير).
3. **تجربة خالية تماماً من الإعلانات**: لا مكتبات إعلانية، لا تتبّع، ولا حتى إذن إنترنت. كل البيانات محلية.

## الشاشات

| الشاشة | المحتوى |
|---|---|
| الرئيسية | التاريخ الهجري (أم القرى) والميلادي، زر عداد سريع أعلى الشاشة، الراتب القادم بعدّاد مباشر، كل المواعيد القادمة |
| الرواتب | رواتب الموظفين، التقاعد، التأمينات، حساب المواطن، الضمان، سكني، التأهيل الشامل، والمناسبات. لكل خدمة: تنبيه مخصص، "إظهار كودجت"، تعديل يوم الصرف، وجدول 6 أشهر |
| عداداتي | العدادات الشخصية مع عدّاد مباشر، تثبيت في الودجت، حذف |
| الأدوات | محوّل التاريخ، حساب العمر (ميلادي وهجري)، الفرق بين تاريخين، الأسعار وضريبة القيمة المضافة 15%، صافي الراتب التقديري |
| المزيد | محرّر الودجت مع معاينة حيّة، المظهر (فاتح/داكن/النظام) |

## الهيكلة (MVVM)

```
com.saudi.salariesapp/
├── data/            # النماذج والمنطق: EventModel، تقويم أم القرى، جدول الصرف، المناسبات، الحاسبات، التخزين المحلي
├── ui/
│   ├── MainViewModel.kt
│   ├── screens/     # الرئيسية، الرواتب، عداداتي، الأدوات، المزيد
│   ├── components/  # البطاقات، العداد المباشر، منتقي الألوان، إدخال التاريخ المزدوج
│   └── theme/       # الألوان، الوضع الداكن، فرض RTL
├── widget/          # SalariesWidget (Glance) + Receiver
├── notifications/   # WorkManager: تحديث الودجت والتنبيهات
└── MainActivity.kt  # نقطة البداية والتنقل (Navigation Compose)
```

## قواعد المواعيد

- التحويل الهجري يستخدم `HijrahChronology` المضمّنة (بيانات أم القرى الرسمية)، لذلك `minSdk = 26`.
- الأيام الافتراضية: رواتب الموظفين 27، التقاعد والتأمينات 1، حساب المواطن 10، الضمان 1، سكني 24، التأهيل الشامل 5.
- إذا وافق يوم الصرف الجمعة أو السبت يُقدَّم إلى الخميس السابق.
- **هذه قيم تقديرية** وليست مصدراً رسمياً؛ يستطيع المستخدم تعديل يوم أي خدمة من داخل التطبيق.

## البناء

```bash
./gradlew testDebugUnitTest   # اختبارات منطق التواريخ والحاسبات
./gradlew assembleDebug       # app/build/outputs/apk/debug/app-debug.apk
```

يبني GitHub Actions ملف APK تلقائياً مع كل push (ملف `.github/workflows/android.yml`).

# الترجمة الحية للشاشة (وحدة `translator`)

تطبيق Android مستقل في نفس المستودع (`translator/`، الحزمة `com.livetranslate.screen`) يقدّم ترجمة **مستمرة وتلقائية**
للشاشة على غرار الترجمة الحية في سامسونج/جوجل: بمجرد التشغيل تبقى الترجمة نشطة وتتحدث تلقائياً عند التنقل بين التطبيقات
والصفحات، ولا تتوقف إلا من زر الإيقاف في التطبيق أو الشريط العائم أو الإشعار الدائم.

## الأوضاع

| | الوضع | آلية العمل |
|---|---|---|
| العرض | **الشاشة الكاملة المستمرة** | كل النصوص الظاهرة تُغطّى بطبقة ترجمة (Canvas Overlay) تتحدث مع التمرير والتنقل |
| العرض | **المربع الزجاجي العائم** | مربع شفاف يُسحب من الشريط ويُكبَّر من المقبض الدائري؛ كل ما تحته يُترجم مباشرة أثناء الحركة |
| المحتوى | **نص** | قراءة شجرة الواجهة عبر Accessibility Service — أسرع وأخف من التقاط الصور |
| المحتوى | **فيديو** | MediaProjection + OCR سريع للترجمات المرئية، والترجمة تظهر في شريط فوق/تحت المنطقة دون تغطيتها |
| المحتوى | **مانغا/صور** | OCR + دمج الأسطر في فقاعات + قراءة ثانية مكبّرة وعالية التباين لكل فقاعة + ترتيب القراءة (RTL/LTR) + تلوين الترجمة بلون خلفية الفقاعة |

المبدّل السريع (نص/فيديو/مانغا) وعكس اتجاه اللغة والإيقاف المؤقت والتبديل بين الشاشة/المربع كلها في الشريط العائم،
ويمكن طيّ الشريط (زر –) إلى دائرة صغيرة قابلة للسحب تُعيد إظهاره بلمسة.

نصوص الكوميكس المكتوبة بحروف كبيرة كلها تُحوَّل لصيغة الجملة قبل الترجمة، وفي المانغا/الفيديو تُعتمد لغة الصفحة لكل الفقاعات.

## اللغات

- الافتراضي: (اكتشاف تلقائي ← العربية)، مع **اتجاه ثنائي**: النص العربي يُترجم إلى اللغة الثانوية (الإنجليزية افتراضياً).
- التعرف على اللغة لكل كتلة نصية بشكل مستقل (ML Kit Language ID)، مع لغة الصفحة الغالبة كتلميح للنصوص القصيرة.
- **اكتشاف تلقائي لنظام الكتابة في الصور والمانغا والفيديو** (ياباني/صيني/كوري/لاتيني/ديفاناغاري) واختيار محرك OCR المناسب،
  ثم اكتشاف اللغة وترجمتها للعربية تلقائياً. يُحفظ الاكتشاف حتى يتغير التطبيق أو المشهد لتوفير الأداء، واللغة المكتشفة تظهر في الشريط العائم.
- حزم لغات للعمل دون إنترنت (ML Kit Translate) مع شاشة لتنزيلها وحذفها؛ تُنزّل تلقائياً عند أول حاجة.

## المعمارية

```
com.livetranslate.screen/
├── core/        # منطق نقي مُختبَر: الهندسة، ترتيب القراءة وتجميع الفقاعات، توجيه اللغات، LRU، بصمة الإطار
├── service/     # LiveTranslationService (Foreground) + ScreenTextAccessibilityService + LivePipeline
├── capture/     # ScreenCaptureEngine (MediaProjection/ImageReader) + OcrEngine (ML Kit) + أخذ لون الخلفية
├── overlay/     # OverlayController (الطبقة، الشريط العائم، مقبض الحجم) + TranslationCanvasView
├── translate/   # TranslationEngine (تعرّف + ترجمة + كاش + تنزيل الحزم) + LanguagePacks
├── settings/    # LiveSettings (StateFlow مستمر) + LiveState
└── ui/          # MainActivity (Compose) + ProjectionPermissionActivity
```

**الأداء:** ذاكرة مؤقتة LRU للترجمات ولنتائج التعرف على اللغة؛ لا يُعاد الرسم إذا لم تتغير بصمة النصوص؛ في أوضاع OCR
تُحسب بصمة إضاءة مصغّرة لكل إطار (مع استبعاد مستطيلات طبقاتنا) ولا يُشغَّل OCR إلا عند تغيّر المحتوى واستقراره؛
الأحداث المتلاحقة تُدمج (debounce بحد أقصى 800ms) والدورة الأحدث تلغي الأقدم.

**ملاحظات تقنية:**
- عند تفعيل خدمة إمكانية الوصول تُنشأ النوافذ كـ `TYPE_ACCESSIBILITY_OVERLAY` (موثوقة: لا تحجب اللمس ومعتمة بالكامل)؛
  وإلا `TYPE_APPLICATION_OVERLAY` بشفافية 80% وهو الحد الذي يفرضه Android 12+ لتمرير اللمس.
- في وضعي المانغا/النص عبر OCR تُخفى الطبقات لحظة الالتقاط (إطاران تقريباً) حتى لا يقرأ OCR ترجماتنا.
- Android 14+ يطلب موافقة التقاط الشاشة في كل جلسة؛ يُطلب الالتقاط للشاشة كاملة لأن الإحداثيات يجب أن تطابقها.
- محرك OCR في ML Kit لا يدعم الحروف العربية/السيريلية؛ الترجمة **من** العربية تعمل في وضع النص (شجرة الواجهة).

```bash
./gradlew :translator:testDebugUnitTest
./gradlew :translator:assembleDebug   # translator/build/outputs/apk/debug/translator-debug.apk
```
