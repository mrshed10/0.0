# القائمة العائمة للتلفاز (TV Floating Menu)

تطبيق Android TV / Smart TV (Kotlin + XML) يعرض **زراً عائماً صغيراً وشبه شفاف** فوق أي تطبيق،
وعند النقر عليه تُفتح **قائمة اختصارات سريعة** بواجهة داكنة وأزرار كبيرة، مصممة للماوس والكيبورد
وتعمل أيضاً بريموت التلفاز.

## محتويات القائمة

| القسم | الوظيفة |
|---|---|
| الصوت | رفع / خفض / كتم + شريط مستوى الصوت مع النسبة المئوية. يعمل بعجلة الماوس أيضاً |
| الإعدادات | فتح إعدادات النظام/التلفاز مباشرة |
| الواي فاي | فتح إعدادات الواي فاي + عرض حالة الاتصال (واي فاي/إيثرنت، قوة الإشارة، وجود إنترنت) |
| تطبيقاتي | التطبيقات المفضلة تُشغَّل بنقرة، زر (+) لاختيار التطبيقات المثبتة، وإزالة أي اختصار |
| أسفل القائمة | إخفاء الزر العائم، إيقاف الخدمة |

## التحكم

| الإجراء | الماوس | الكيبورد | الريموت |
|---|---|---|---|
| فتح القائمة | نقر الزر العائم | أيقونة "فتح القائمة العائمة" | أيقونة "فتح القائمة العائمة" |
| نقل الزر | سحب (يلتصق بأقرب حافة) | — | — |
| التنقل | مرور الماوس يميّز الزر | الأسهم | الأسهم |
| تنفيذ | نقر | Enter | OK |
| إغلاق | نقر خارج القائمة | Esc | رجوع |
| الصوت | عجلة الماوس على شريط الصوت | ‎+ / -‎ و M للكتم | أزرار الصوت |
| حذف اختصار | زر يمين ← وضع التعديل | Delete | ضغطة مطولة ← وضع التعديل |

> لماذا لا يُفتح الزر العائم بالكيبورد مباشرة؟ نافذة الزر غير قابلة للتركيز عمداً حتى لا تسرق أزرار
> الريموت/الكيبورد من الفيديو الذي تشاهده. لذلك أضفنا أيقونة ثانية "فتح القائمة العائمة" تفتح القائمة فوراً،
> ويمكن ربطها بزر مختصر في الريموت إن كان التلفاز يدعم ذلك. وزر "فتح القائمة" موجود أيضاً في الإشعار.

## الصلاحيات (AndroidManifest.xml)

| الصلاحية | السبب |
|---|---|
| `SYSTEM_ALERT_WINDOW` | الظهور فوق التطبيقات الأخرى. تُطلب عند أول تشغيل مع شرح |
| `FOREGROUND_SERVICE` + `FOREGROUND_SERVICE_SPECIAL_USE` | العمل في الخلفية دون أن يغلقه النظام |
| `RECEIVE_BOOT_COMPLETED` | التشغيل التلقائي عند تشغيل التلفاز (قابل للإيقاف) |
| `MODIFY_AUDIO_SETTINGS` | التحكم بالصوت |
| `ACCESS_NETWORK_STATE`, `ACCESS_WIFI_STATE` | عرض حالة الشبكة وقوة الإشارة |
| `POST_NOTIFICATIONS` | إشعار الخدمة (اختياري، Android 13+) |
| `<queries>` لـ LAUNCHER و LEANBACK_LAUNCHER | قراءة التطبيقات المثبتة القابلة للتشغيل دون صلاحية `QUERY_ALL_PACKAGES` الواسعة |

### إذا لم تظهر شاشة منح الصلاحية على التلفاز

بعض أجهزة Google TV / Android TV تخفي شاشة "الظهور فوق التطبيقات الأخرى". في هذه الحالة فعّلها
من الكمبيوتر (يظهر الأمر نفسه داخل التطبيق):

```bash
adb connect <IP-التلفاز>
adb shell appops set com.tvtools.floatingmenu SYSTEM_ALERT_WINDOW allow
```

## الهيكلة

```
tvoverlay/src/main/java/com/tvtools/floatingmenu/
├── MainActivity.kt        # شاشة الإعداد: الصلاحيات، تشغيل/إيقاف، خيارات
├── QuickMenuActivity.kt   # أيقونة بلا واجهة تفتح القائمة مباشرة
├── AppPickerActivity.kt   # اختيار التطبيقات المثبتة مع بحث بالكيبورد
├── OverlayService.kt      # خدمة أمامية تدير الزر والقائمة + الإشعار
├── BootReceiver.kt        # التشغيل التلقائي عند الإقلاع
├── overlay/               # FloatingBubble (سحب/نقر)، MenuPanel (القائمة)، KeyInterceptLayout
├── system/                # VolumeController، NetworkStatus، SystemShortcuts، OverlayPermission
├── data/                  # Prefs (حفظ محلي)، AppRepository (قراءة وتشغيل التطبيقات)
└── ui/                    # المحوّلات (Adapters) وتأثير التركيز
```

كل الإعدادات (التطبيقات المفضلة وترتيبها، موضع الزر، إظهاره، التشغيل التلقائي) محفوظة في
`SharedPreferences` وتبقى بعد إعادة التشغيل.

## البناء والتثبيت

```bash
./gradlew :tvoverlay:testDebugUnitTest
./gradlew :tvoverlay:assembleDebug   # tvoverlay/build/outputs/apk/debug/tvoverlay-debug.apk
adb install -r tvoverlay/build/outputs/apk/debug/tvoverlay-debug.apk
```

أو افتح المشروع في Android Studio واختر الوحدة `tvoverlay`. يبني GitHub Actions الملف تلقائياً
ويرفعه باسم `tv-floating-menu-debug-apk`.

- minSdk 23 (Android 6) — targetSdk 35.
- على الأجهزة التي يُدار فيها الصوت عبر HDMI-CEC أو مكبر خارجي قد يكون مستوى الصوت "ثابتاً"؛
  يظهر تنبيه بذلك داخل القائمة.
